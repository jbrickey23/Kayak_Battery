# Kayak_Battery

Durable engineering project: high-capacity LiFePO4 under-seat battery system for the Native Watercraft Titan X 10.5.

**Goal:** Maximize installed usable energy and available hull volume while minimizing net system weight, total cost and irreversible hull modifications. The prior ~200Ah to ~280Ah / +40% energy comparison is a **benchmark**, not a decision to use any cell count or model. Consolidating a separate ~50Ah electronics battery may offset finished-pack weight.
